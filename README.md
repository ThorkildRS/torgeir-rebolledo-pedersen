# Torgeir Rebolledo Pedersen — Forfatterside

Minimalistisk nettside for forfatterskapet til Torgeir Rebolledo Pedersen.

## Kom i gang

Åpne `index.html` direkte i nettleseren, eller kjør en lokal server:

```bash
npx serve .
```

## Struktur

```
index.html   — Hele nettsiden (HTML, CSS, JS i én fil)
```

## Fonter

Siden bruker Google Fonts (Cormorant Garamond + Libre Franklin) via CDN.
